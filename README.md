# SpaceShooter

This is not a finished game. It's an educational project that I use to learn Babylon.js engine.

It also serves to showcase my coding skills to potential employers.

Live demo: https://ncwdev.github.io/SpaceShooter/

To increase FPS in Chrome, open Settings -> System and enable "Use graphics acceleration when available" option.

To gain even more performance, ensure that Chrome uses the discrete GPU. Press Win + I, go to System -> Display -> Graphics Settings, add chrome.exe, and select the GPU for high performance.

The method should work for all other browsers too.
